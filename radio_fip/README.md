# FIP Radio Plugin for Volumio

VERSION: 1.0.3 of 16-08-2026

## Description

`radio_fip` is a Volumio music service plugin providing access to the FIP radio channels from Radio France.

The plugin provides:

- 13 FIP radio stations
- AAC 192 Kbps HiFi streams
- Station logos
- Track metadata (artist, title, album)
- Album artwork when available
- FIP default cover when no artwork is available

## Supported Stations

- FIP National
- FIP Electro
- FIP Groove
- FIP Hip Hop
- FIP Jazz
- FIP Metal
- FIP Nouveautés
- FIP Pop
- FIP Reggae
- FIP Rock
- FIP Sacré Français
- FIP World
- FIP Cultes

The station “FIP Sacré Français” does not display album covers or track metadata (artist, title, album) because I have not been able to find the metadataId for this station.

## Installation

The **Radio FIP** plugin is now available in beta on the **Volumio Plugin Store**.

To access beta plugins in Volumio, enable the Plugin Test Mode:

1. Open the Volumio web interface.
2. Go to:

   http://volumio.local/dev

3. Enable "Plugin Test Mode".
4. Go to:

   Settings → Plugins → Search plugins

5. Search for "Radio FIP" and install the plugin.
